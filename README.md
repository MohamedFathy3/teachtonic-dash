# 🚀 LMS Dashboard (Admin & Instructor)

A modern, scalable Learning Management System (LMS) Dashboard built with React, TypeScript, and Tailwind CSS.

This project includes two main dashboards:
- Admin Dashboard
- Instructor Dashboard

Designed with a clean SaaS UI inspired by platforms like Udemy and Teachable.

---

## 🧠 Features

### 🌍 Global Features
- 🌐 Multi-language support (Arabic 🇪🇬 RTL + English 🇺🇸 LTR)
- 🎨 Dark / Light mode
- 📱 Fully responsive design (mobile + tablet + desktop)
- ⚡ Fast and optimized UI
- 🧭 Sidebar + Top Navbar layout

---

## 🧑‍💼 Admin Dashboard

### 📊 Dashboard Overview
- Users, Courses, Instructors, Revenue stats
- Charts & analytics
- Recent activity

### 👥 Users Management
- View all users
- Roles: Admin / Instructor / Student / Assistant
- Search, filter, pagination

### 👨‍🏫 Instructors
- View instructors list
- Detailed instructor profile with:
  - Overview
  - Courses
  - Students
  - Exams
  - Assignments
  - Assistants
  - Earnings

### 🎓 Courses
- Manage all courses
- Assign instructors
- Publish / Draft status

### 💳 Payments
- Transactions list
- Payment status
- Revenue tracking

### ⭐ Reviews
- Manage course reviews
- Approve / delete feedback

### 🔔 Notifications
- Send announcements to users

### 📈 Reports
- Revenue analytics
- Top courses & instructors

### ⚙️ Settings
- Platform configuration

---

## 👨‍🏫 Instructor Dashboard

### 📊 Dashboard
- Personal stats (students, courses, earnings)
- Activity overview

### 📚 My Courses
- Create and manage courses
- Upload lessons (videos / PDFs)

### 👨‍🎓 Students
- View enrolled students
- Track progress
- Review students

### 📝 Exams
- Create exams
- Add questions
- View results

### 📄 Assignments
- Create assignments
- Review submissions

### 📂 Content Management
- Upload PDFs / videos
- Attach to lessons
- Track usage

### 📈 Analytics
- Course performance
- Engagement & completion rates

### 💰 Earnings
- Revenue tracking
- Withdraw requests

### 👥 Assistants
- Add assistants
- Manage permissions

### 🌐 Website Builder
Each instructor has a personal website:
- URL: `/instructor/{slug}`
- Enable / Disable website
- Choose template (2 options)
- Customize:
  - Logo
  - Banner
  - Colors
- Live preview

### ⚙️ Settings
- Profile settings
- Language & theme
